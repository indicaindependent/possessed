# POSSESSED showcase artwork

Static, original vector illustrations created for this repository's contest presentation. These are promotional illustrations, not gameplay screenshots.

- `possessed-cover.svg`: haunted-house cover.
- `possessed-roles.svg`: Ghost and Hunter role illustration.

The artwork takes its palette and motifs from the game source. No animation, external images, scripts or remote fonts are required. The playable game is at https://possessed.base44.app.

The repository's game source remains a separately synchronized source snapshot. Presentation updates do not automatically synchronize the game or publish a new app version.
